# v1.25 - Fix Windows trailer player configuration errors

Local candidate **1.25.0+26**. Not a published release.

Windows trailer navigation now supplies the app identity as the browser referrer,
using WebView2's navigation API. An HTTP header override alone left the browser
referrer empty and caused YouTube's video player configuration error.

No change to click-to-load behavior, trailer selection or normal video streaming.
A native Windows check reproduced the previous error repeatedly, then verified
the corrected path reaches the player and advances decoded 1280x720 video frames.

See [diagnosis and verification](../TRAILER_PLAYER_FIX_2026-10-20.md).

Fresh gate: 270 Rust and 396 Flutter tests passed (9 skips), with Clippy, analysis
and host build. Normal Windows release build and unsigned setup/portable packages
passed verification under `dist/windows/v1.25`. Not installed or published.
