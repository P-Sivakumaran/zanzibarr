# zanzibarr v1.16 — Reliable playback resume

Local Windows candidate: **1.16.0+17**. Not a published release.

- Reopening the same search release restores its last saved position even when
  downloading it again creates a new temporary NZB filename. Indexer identity,
  release link and selected episode keep unrelated videos separate.
- Load history before opening media and give the native player its start position
  directly. Periodic saves cannot race a delayed history lookup.
- Save immediately on pause, backgrounding and playback errors, as well as every
  five seconds and when leaving the player. An abrupt crash can still lose the
  interval since the last successful checkpoint.
- Preserve saved progress when history cannot be read and show a localized
  storage warning. Preserve favorites and metadata when moving a history record.

Completed videos still restart from the beginning. Different releases/edits of
one title do not share a playhead automatically.

Verification and Windows packaging are in progress. The separately reported
playback cessation has not been reproduced or attributed to a specific cause.
