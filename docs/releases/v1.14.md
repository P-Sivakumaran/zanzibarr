# zanzibarr v1.14 — Claude and Gemini film chat

Local candidate: **1.14.0+15**. Not a published release.

- Choose Claude API or Gemini API for in-app film recommendations, descriptions,
  saved playlists and release search.
- Save provider API keys in OS secure storage. Gemini also supports a registered
  Google Desktop OAuth client, browser sign-in, cancellation and token refresh.
- Open AI connections from film chat or Settings → MCP & AI. Switching providers
  starts a new conversation while retaining saved playlists.
- Keep failed drafts and saved settings on errors; bound and cancel requests.

See [setup](../AI_CONNECTIONS.md). API keys or Google client registration are
required. Live provider authentication/inference remains unverified.

screenshot skips; Clippy, analysis and native build passed. Windows release,
installer and portable ZIP built; hashes, ZIP integrity, native components and
