# zanzibarr v1.10 — fork release candidate

Prepared for P-Sivakumaran/zanzibarr. This document describes the candidate;
it does not indicate that every platform has been built or published.

## Changes

Library management (`docs/LIBRARY_MANAGEMENT_PLAN_2026.md`, phases 1–5):

- Persistent media identity on playback history: structured-search downloads
  now carry `imdbId`/season/episode through to resume, independent of file
  selection order.
- Continue Watching and Up Next consolidation: completed episodes stay in
  history (used to compute "Sıradaki"); the next unwatched episode for a show
  is suggested from history alone, no network call, and opens a prefilled
  (not auto-run) structured search.
- Show tracking: "Track this show" on the metadata screen, a user-triggered
  "Check for new episodes" action (opens prefilled search and runs it
  immediately), and a stale-check reminder. No background polling.
- Resume durability: a vanished temp-cached NZB is now re-downloaded from its
  original indexer and source URL when the user resumes it, instead of
  failing silently. Recovery preserves the saved position atomically and
  never evicts another video's resume point.
- Manual curation: a favorite flag independent of watch progress (exempt
  from the 25-entry history budget), explicit mark watched/unwatched without
  replaying the file, and dedicated Favorites / Recently watched sections.

## Known limits

Live indexer/OMDb access, physical TV navigation, phone playback, casting and
screen-reader validation remain pending. The "Sıradaki"/next-episode guess
assumes a simple episode+1 within the same season (no season-rollover
detection, since total-episode-count isn't known without a network call).
New copy is English/Turkish with English fallbacks in other locales. Web is
unsupported because the engine needs NNTP.

See [release runbook](../RELEASING.md) for build, signing and promotion steps.
