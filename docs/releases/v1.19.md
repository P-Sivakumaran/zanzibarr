# v1.19 - Room to browse

- Wider Home, title and discovery layouts, with responsive utility controls.
- Direct, labelled playlist access from Home and the saved library.
- Posters and confirmed title metadata shared by recommendations and playlists.
- Source-labelled animated rating meters and playlist film/TV composition.
- Reduced-motion support, compact artwork fallbacks and artwork refresh fix.

Artwork matching requires an optional OMDb key; image loading is opt-in.
Existing playlists and search continue without metadata configuration.
