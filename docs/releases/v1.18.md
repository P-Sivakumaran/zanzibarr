# zanzibarr v1.18 - Artwork, library and organised shows

Local candidate: **1.18.0+19**. Not a published release.

- Home adapts the reviewed Minimalist and Cinematic Figma designs, preserving
  the existing logo, NZB tools, playback recovery, history and favorites.
- Browse films and TV through optional OMDb or the existing provider plugins.
  Open a full title page, save films/shows, filter a library and sort by title,
  year or recently saved. Tracked shows also appear in the library.
- Enable **Load artwork** in Browse or My library for optional public CDN
  requests. Artwork is off by default and independent of playback. Turning it
  off clears the in-memory image cache; missing/failed art keeps stable slots.
- Select seasons (including Specials) to explicitly fetch episode lists.
  Episode searches retain the parent IMDb ID and exact season/episode. Future
  episodes cannot start a release search. Spoiler titles are hidden by default.
- IMDb and Rotten Tomatoes retain their source and scale. IMDb opens the
  confirmed title; **Search Rotten Tomatoes** opens a labelled search rather
  than inventing a review URL.
- **App language** opens the existing locale choices alongside separate audio
  and subtitle preferences. Player menus normalise language codes, preserve
  region/unknown values and label detected/external tracks. Manual choices
  take priority; no release language or country flag is guessed.
- AI recommendations open the same explicit title-match journey before release
  search. Raw indexer searches remain available without metadata credentials.

OMDb metadata uses its source language. New discovery/library copy falls back to
English. This does not add TMDB, automatic trending catalogs, review text,
authoritative forced/SDH classification, episode stills or background scans.
Old metadata plugins remain usable; season browsing needs the optional
`metadata_season` tool. Saved plugin metadata retains its provenance; Home
refreshes through OMDb and still displays saved data if that lookup is unavailable.
