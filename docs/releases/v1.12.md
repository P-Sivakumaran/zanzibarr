# zanzibarr v1.12 — film chat and playlists

Local candidate: **1.12.0+13**. Not a published release.

- Discover films from Home: chat about moods, genres, eras or similar titles.
  Follow-up requests keep recent conversational context.
- Receive film cards with spoiler-free descriptions and reasons, then save
  individual picks or the whole response into named, ordered playlists.
- Rename/reorder/remove saved films and find releases through existing indexer
  search. Playlists persist on the device. Automatic next-film playback is not
  included.
- Connect through the official local Codex app-server with managed ChatGPT
  browser sign-in, automatic Windows executable discovery and visible status.
- Stop replies, retry failed drafts and preserve playlists on storage failures.
  No model requests run until Send is pressed.

See [setup and scope](../FILM_CHAT.md). Live OAuth/inference, device playback
and physical remote validation remain separate from local fixture tests.
