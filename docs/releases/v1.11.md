# zanzibarr v1.11 — integrations candidate

Local candidate: **1.11.0+12**. Not a published release.

- Settings has an Integrations action for opt-in local MCP access. Assistants
  can read library/playback state; indexer search and pause/resume/seek each
  require enabling the relevant permission. No source URLs, filesystem paths
  or provider credentials are returned by the built-in tools.
- External MCP servers can be added with HTTPS (or loopback HTTP), optional
  bearer authentication, tool discovery and explicit tool calls.
- MCP metadata-provider plugins can participate in title lookup and structured
  release search without an OMDb key. Queries and rating provenance are labeled.
- Codex subscription sign-in uses the official local app-server and OS keyring
  in a separate profile. This is account management, not an embedded chat UI.
- Claude Code/Desktop can use Zanzibarr's MCP tools with their own sign-in.
  Anthropic does not support Claude.ai subscription login inside third-party
  apps. Zanzibarr does not read or import Claude session credentials.
- A Python stdio bridge supports local clients without direct HTTP transport.
  Python 3.10+ is required for that bridge; direct HTTP clients do not need it.

See [integration setup and contracts](../INTEGRATIONS.md).

Integration copy is currently English in all locales, with an explicit notice.
Local protocol/fixture tests do not prove live provider service compatibility,
physical remote input, playback/casting control or real OAuth completion.
