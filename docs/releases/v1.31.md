# Zanzibarr v1.31 — Interface refinement and reliability

## Interface

- Introduce a shared Material 3 theme with neutral dark/light surfaces, clearer
  typography and consistent menus, dialogs, inputs and visible focus indicators.
- Keep branding aligned with Home content and show labelled Library and
  Playlists shortcuts on wide windows. Preserve compact navigation.
- Organize Settings into Viewing, Playback services, Optional connections and
  About & privacy, adapting to narrow windows and larger text.
- Display confirmed title names and episode labels in history without changing
  release identity, saved progress or rematch corrections.
- Fix Future-returning state callbacks during series loading and retry.
- Include an offline, sample-data UI review entrypoint and rendered gallery tool.

## Reliability and platform foundations

- Bound local streaming listener concurrency, header waits, stalled writes and
  segment-cache residency; retain byte-range and authenticated casting behavior.
- Prevent stale native playback work from replacing a newer session.
- Retain recoverable local library snapshots and improve verified secure-storage
  migration for provider settings.
- Require configured publisher trust for automatic Windows installation. Until
  real trust pins are available, use the release-page download action.
- Pin CI actions/toolchains and Android native inputs, validate native alignment,
  and retain platform artifact inventories and dependency audit evidence.
- Include offline draft terms/privacy and isolated Windows edition development
  foundations. Clean's catalogue/playback remains closed; new edition updaters
  remain disabled. These are not completed public edition products.

## Candidate status

Version **1.31.0+32**. The Windows setup and portable ZIP are unsigned development
candidates. The draft is not promoted to the stable updater channel. Installer
validation and final source verification are recorded separately in
`docs/RELEASE_CANDIDATE_1.31.md`.

The unfinished hosted-video catalogue is excluded from this release commit and
its packages. Existing metadata and optional integrations retain their provider
requirements. No new live provider, streaming or device compatibility claims
are made. Clean-user installation, physical playback/seek/casting, screen-reader
and TV remote checks, real publisher signing and finalized legal/operator details
remain prerequisites for applicable public distribution claims.
