# v1.24 - Film-card details, embedded trailers and icon refinement

Local candidate: **1.24.0+25**. Not a published release.

- Open film information by clicking an AI suggestion or playlist card, its title
  or poster, or the explicit Details & trailer action. Search/save actions remain
  independent, and the new route opens before network identification finishes.
- Show a user-loaded embedded YouTube trailer on title pages, selected from
  official trailers/teasers returned by TMDB for the verified title identity.
- Reuse existing secure TMDB configuration and bounded, persistent enrichment
  cache; fetch videos with credits/topics in the same details request.
- Refine the sun position, glow and small-size clarity of the Zanzibarr icon,
  preserving the play triangle, palms, sailboat and transparent exterior.

Trailer discovery needs a configured TMDB read access token. Windows embedding
needs Microsoft Edge WebView2 Runtime. Trailers do not autoplay; YouTube opens only
on request. External viewing is available when embedding is unavailable. Linux
uses external viewing; other native platforms require device verification.

See [implementation and verification](../FILM_CARD_TRAILERS_2026-10-20.md).

Fresh gate: 270 Rust and 393 Flutter tests passed (9 skips), with Clippy, analysis,
host build and Windows release build. Unsigned local setup/portable packages are
ready under `dist/windows/v1.24`; hashes, ZIP integrity and components verified.
Not installed/published; live native trailer playback remains unverified.
