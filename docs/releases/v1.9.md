# zanzibarr v1.9 — fork release candidate

Prepared for P-Sivakumaran/zanzibarr. This document describes the candidate;
it does not indicate that every platform has been built or published.

## Changes

- Multiple named indexer profiles, ordering, search toggles, independent
  pagination/retry and deterministic duplicate handling.
- Optional OMDb title/IMDb lookup with synopsis and source-labelled ratings;
  API keys stay in secure storage. Test an unsaved key from Settings.
- Capability-aware IMDb/TVDB, season and episode search with title fallback.
- Improved phone player controls, setup recovery, draft protection, TV focus,
  large-text layouts, filename inspection and sanitized error diagnostics.
- Request-owned bounded prefetch and selected-entry PAR2 repair fixes.
- Search profile load failures now offer retry; pagination counts all RSS
  entries, including entries that cannot be played.
- Windows per-user setup executable with shortcuts, uninstall support and
  bundled C++ runtime; portable ZIP retained. Ubuntu 24.04 x64 gains a `.deb`.
- Fork updater endpoint, automated verification, tag/version validation,
  checksums and draft releases for final artifact review.
- Updated branding and bundled League Mono font.

## Packages

| Platform | Artifact | Status / requirements |
|---|---|---|
| Windows x64 | `zanzibarr-windows-x64-setup.exe` | Per-user installer; no administrator rights required |
| Windows x64 | `zanzibarr-windows-x64.zip` | Extract the entire bundle, then run `zanzibarr.exe` |
| Ubuntu 24.04 x64 | `zanzibarr-linux-x64.deb` | CI build; install with `sudo apt install ./zanzibarr-linux-x64.deb` |
| Linux x64 | `zanzibarr-linux-x64.tar.gz` | CI build; system GTK, libmpv and secret service required |
| Android / TV | `zanzibarr-android-universal.apk` and ABI APKs | CI build requires persistent signing secrets |
| iOS | `zanzibarr-ios-unsigned.ipa` | CI build; user must sign before sideloading; no TestFlight |
| macOS arm64 | Manual signed package | Requires macOS and maintainer signing environment; not built on Windows |

Windows binaries are unsigned unless a distribution certificate is supplied
outside this repository. Android upgrades require the same signing certificate
as the installed app. Fork updates are fetched from this fork's releases.

## Known limits

Live indexer/OMDb access, physical TV navigation, phone playback, casting and
screen-reader validation remain pending. Archive selection identifies archive
sets, not individual files inside a single archive. The reported Gran Torino
RAR4 parsing issue remains open. New copy is English/Turkish with English
fallbacks in other locales. Web is unsupported because the engine needs NNTP.

See [release runbook](../RELEASING.md) for build, signing and promotion steps.
