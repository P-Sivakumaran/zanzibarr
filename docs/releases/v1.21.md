# v1.21 - Automatic artwork and useful rating context

Local candidate: **1.21.0+22**. Not a published release.

- Automatically identify and enrich suggestions, playlists and resume titles
  through configured metadata access, with Rematch title for corrections.
- Preserve corrections and use resolved title identities for release search.
- Show RT percentage-positive, IMDb user-rating and Metacritic scales with
  exact review/vote totals when supplied. Missing counts stay unavailable.
- Bound and coalesce automatic requests; retain optional artwork loading,
  secure credentials, playback identity and reduced-motion support.

Review totals are provider-dependent; standard OMDb data may omit critic counts.
See [implementation and verification](../AUTOMATIC_METADATA_RATINGS_2026-10-19.md).
