# v1.22 - Durable matches, cast and richer title details

Local candidate: **1.22.0+23**. Not a published release.

- Remember chosen title identities independently of the artwork/ratings cache;
  cache eviction no longer sends a corrected suggestion through title search.
- Show cast directly, with optional character names and portraits, plus director,
  writer, awards, release date, country and original title languages.
- Add optional TMDB cast/artwork/topic enrichment and optional Wikidata filming
  locations, distinct from narrative settings. Topics are hidden until opened.
- Add a configured MCP metadata connection as an optional review-data source.
  Replace source scores and their verified counts together, with attribution.
- Persist bounded additional-data caches, missing results and retry delays;
  preserve base title access while optional details load.

New sources are off until configured. TMDB needs a read access token; critic
count enrichment needs a configured metadata connection returning the documented
score/count contract. This candidate does not include a Fabric subscription or
claim live review-count coverage. Unsigned Windows setup and portable ZIP are available locally under
`dist/windows/v1.22`; checksums and bundle contents verified. Clean-install and
live playback checks remain outstanding.
